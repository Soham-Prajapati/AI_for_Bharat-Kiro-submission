## Practice Session Guidelines

### Before Each Session

**Presenter:**
- [ ] Review previous feedback
- [ ] Practice problem areas
- [ ] Prepare equipment
- [ ] Arrive 10 min early
- [ ] Positive mindset

**Team:**
- [ ] Print feedback forms
- [ ] Setup timer
- [ ] Setup recording (if applicable)
- [ ] Prepare to give constructive feedback
- [ ] Be supportive!

### During Each Session

**Presenter:**
- Start when ready
- Complete full demo (don't stop)
- Note any issues mentally
- Finish strong

**Team:**
- Time each section
- Take notes on feedback form
- Don't interrupt (unless stress test)
- Be engaged audience

### After Each Session

**Immediate (5 min):**
- [ ] Presenter records times
- [ ] Team fills feedback forms
- [ ] Quick verbal feedback round

**Debrief (15 min):**
- [ ] Review timing breakdown
- [ ] Discuss what worked well
- [ ] Identify top 3 improvements
- [ ] Plan focus for next session

**Follow-up:**
- [ ] Update practice tracker
- [ ] File feedback forms
- [ ] Schedule next session
- [ ] Individual practice as needed
