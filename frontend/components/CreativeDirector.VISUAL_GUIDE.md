## Color Coding System

### Score Ranges

```
🟢 GREEN (76-100)    ▓▓▓▓▓▓▓▓▓▓  Excellent
   - Scores above 75
   - Indicates strong performance
   - Minimal improvements needed

🟡 YELLOW (50-75)    ▓▓▓▓▓▓▓░░░  Good
   - Scores between 50-75
   - Good performance with room for improvement
   - Moderate attention needed

🔴 RED (0-49)        ▓▓▓▓░░░░░░  Needs Work
   - Scores below 50
   - Requires significant improvement
   - High priority for optimization
```

## Accessibility Features

- **Semantic HTML**: Proper heading hierarchy (h2, h3)
- **Color + Text**: Scores use both color and text labels
- **Keyboard Navigation**: All interactive elements are keyboard accessible
- **Screen Readers**: Descriptive labels and ARIA attributes
- **Focus Indicators**: Visible focus states on interactive elements

## Print Styles

When printed, the component:
- Removes animations
- Adjusts colors for better contrast
- Optimizes layout for paper
- Hides interactive elements
