## Practice Tips

### Before Each Session

- [ ] Review feedback from previous session
- [ ] Focus on 1-2 specific improvements
- [ ] Have timer ready
- [ ] Have feedback form ready for audience
- [ ] Record video if possible

### During Each Session

- [ ] Start timer at beginning
- [ ] Note section transitions
- [ ] Stay in character (don't break to comment)
- [ ] Finish completely even if over time

### After Each Session

- [ ] Record times immediately
- [ ] Write down immediate thoughts
- [ ] Collect feedback forms
- [ ] Identify top 3 improvements
- [ ] Schedule next session

---

## Readiness Checklist

By Session 10, you should be able to check ALL of these:

- [ ] Total time consistently 4:50 - 5:10
- [ ] Hook grabs attention in first 10 seconds
- [ ] Problem is clear and relatable
- [ ] Solution is concise and compelling
- [ ] Demo flows smoothly without technical issues
- [ ] Technical section shows expertise without jargon
- [ ] Impact section is memorable
- [ ] Transitions between sections are smooth
- [ ] Voice is confident and energetic
- [ ] Body language is open and engaging
- [ ] Eye contact with audience (not reading)
- [ ] Handling Q&A confidently
- [ ] Confidence rating 9/10 or higher

**If you can't check all boxes, schedule more practice sessions!**
