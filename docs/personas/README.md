This folder now contains **persona definitions** for expert advisors that can be used within your work sessions.

---

## What Are Personas?

Personas are specialized expert advisors you can invoke during your work:

- **ARCHITECT** - System design, tech stack decisions
- **DESIGNER** - UX/UI, user flows, wireframes
- **DEVOPS** - Deployment, CI/CD, infrastructure
- **PLANNER** - Project planning, task breakdown
- **PRESENTER** - Demo preparation, pitch coaching
- **QA** - Testing strategy, quality gates
- **RESEARCHER** - API research, tool evaluation
- **STRATEGIST** - Business strategy, feasibility
- **TECH_WRITER** - Documentation, API guides

---

## How to Use Personas

### Option 1: Direct Request (Recommended)
Just ask in your chat:
```
"Act as a security expert and review my S3 service for vulnerabilities"
"Think like an architect and design the database schema"
"Be a UX designer and critique this user flow"
```

### Option 2: Reference Persona Files
```
"Review my code using the guidelines in docs/personas/ARCHITECT.md"
```

---

## When to Use Personas

- **Complex decisions** - Need expert perspective
- **Code review** - Security, architecture, quality
- **Design review** - UX, accessibility, user flows
- **Planning** - Breaking down large tasks
- **Documentation** - Writing clear guides

---

## Personas vs Team Prompts

| Type | Purpose | When to Use |
|------|---------|-------------|
| **Team Prompts** (`/PROMPTS.md`) | Start your work session | Beginning of work |
| **Personas** (this folder) | Get expert advice | During work, when stuck |

---

## Example Workflow

1. **Start work** with your team prompt from `/PROMPTS.md`
2. **During work**, invoke personas as needed:
   - "Act as ARCHITECT and review this design"
   - "Think like QA and suggest test cases"
   - "Be a SECURITY expert and audit this code"
