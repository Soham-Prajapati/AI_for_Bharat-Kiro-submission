# 📤 Upload Content Guide

## Supported Formats

### Video Files
- **MP4** - Recommended (best compatibility)
- **MOV** - Apple QuickTime format

### Audio Files
- **MP3** - Compressed audio
- **WAV** - Uncompressed audio

### Text Files
- **TXT** - Plain text
- **PDF** - Documents

## File Size Limits

| Plan | Max File Size |
|------|---------------|
| Free | 500 MB |
| Pro | 2 GB |

## How to Upload

### Method 1: Drag & Drop

1. Click "Upload" button
2. Drag file from your computer
3. Drop into upload area
4. File uploads automatically

### Method 2: Browse Files

1. Click "Upload" button
2. Click "Browse Files"
3. Select file
4. Click "Open"
5. Click "Upload"

## Add Metadata

### Required Fields

**Title:**
- Name of your content
- Max 200 characters
- Example: "Butter Chicken Recipe"

**Domain:**
- Select category:
  - Food & Cooking
  - Education & Learning
  - Travel & Adventure
  - Product Reviews

### Optional Fields

**Description:**
- Brief summary
- Max 500 characters

**Tags:**
- Keywords for search
- Max 10 tags
- Example: cooking, indian, recipe

**Language:**
- Content language
- Auto-detected if not specified

## Upload Progress

**Status Indicators:**
- **Uploading** - File transfer in progress
- **Processing** - AI analyzing content
- **Completed** - Ready to use
- **Failed** - Error occurred

**Progress Bar:**
- Shows percentage complete
- Estimated time remaining
- Upload speed

## Troubleshooting

### File Too Large

**Error:** "File exceeds size limit"

**Solutions:**
- Compress video (use HandBrake)
- Split into smaller parts
- Upgrade to Pro plan

### Unsupported Format

**Error:** "File format not supported"

**Solutions:**
- Convert to MP4 (use FFmpeg)
- Check file extension matches format
- Try different file

### Upload Failed

**Error:** "Upload failed"

**Solutions:**
- Check internet connection
- Try again
- Use smaller file
- Contact support

### Slow Upload

**Causes:**
- Large file size
- Slow internet
- Server busy

**Solutions:**
- Upload during off-peak hours
- Use wired connection
- Compress file first

## Best Practices

**Before Uploading:**
- Check file format
- Verify file size
- Prepare metadata
- Stable internet connection

**During Upload:**
- Don't close browser
- Don't sleep computer
- Monitor progress

**After Upload:**
- Wait for processing
- Review results
- Edit if needed
- Generate outputs

## Tips

- **Compress videos** to save time
- **Add descriptive titles** for better results
- **Select correct domain** for accurate analysis
- **Use tags** to organize content
- **Upload in batches** for efficiency
