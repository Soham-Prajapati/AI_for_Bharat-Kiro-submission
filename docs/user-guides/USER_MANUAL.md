# 📖 User Manual

## Getting Started

### 1. Sign Up

1. Go to https://content-ai.example.com
2. Click "Sign Up"
3. Enter email and password
4. Verify email
5. Complete profile

### 2. Choose Plan

**Free Tier:**
- 10 videos/month
- 500MB max file size
- Basic features

**Pro Tier ($29/month):**
- Unlimited videos
- 2GB max file size
- All features
- Priority support

### 3. First Upload

1. Click "Upload" button
2. Drag & drop your video
3. Add title and select domain
4. Click "Analyze"
5. Wait 30-60 seconds
6. View results!

## FAQs

**Q: How long does processing take?**  
A: 30-60 seconds for most videos.

**Q: What file formats are supported?**  
A: MP4, MOV, MP3, WAV, TXT, PDF.

**Q: Can I cancel anytime?**  
A: Yes, cancel anytime. No refunds for partial months.

**Q: Is my content private?**  
A: Yes, your content is private and encrypted.

**Q: Can I download generated content?**  
A: Yes, download in multiple formats.

**Q: Do you train AI on my content?**  
A: No, we never train on user content.
