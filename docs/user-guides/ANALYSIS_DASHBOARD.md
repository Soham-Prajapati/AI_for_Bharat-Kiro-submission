# 📊 Analysis Dashboard Guide

## Overview

After uploading content, AI analyzes it and shows results in the Analysis Dashboard.

## Summary View

**What You See:**
- **Main Summary** - Brief overview of content
- **Key Points** - Important highlights
- **Duration** - Content length
- **Word Count** - For text content

**Example:**
```
Summary: A cooking tutorial showing how to make butter 
chicken with step-by-step instructions. Covers marinating, 
grilling, and sauce preparation.

Duration: 3 minutes 45 seconds
Key Points: Marinating technique, sauce recipe, plating tips
```

## Keywords

**Extracted Keywords:**
- Most important words/phrases
- Ranked by relevance
- Used for SEO optimization

**Example:**
- butter chicken (95% relevance)
- indian cuisine (88% relevance)
- cooking tutorial (82% relevance)
- recipe (75% relevance)

**Use Keywords For:**
- YouTube tags
- Instagram hashtags
- Blog SEO
- Search optimization

## Domain Detection

**AI Detects:**
- Food & Cooking
- Education & Learning
- Travel & Adventure
- Product Reviews

**Confidence Score:**
- 90-100%: Very confident
- 70-89%: Confident
- 50-69%: Uncertain
- <50%: Low confidence

**If Wrong Domain:**
1. Click "Change Domain"
2. Select correct domain
3. Click "Re-analyze"

## Sentiment Analysis

**Sentiment Types:**
- **Positive** - Upbeat, happy, exciting
- **Neutral** - Informative, factual
- **Negative** - Critical, sad, serious

**Sentiment Score:**
- +1.0: Very positive
- 0.0: Neutral
- -1.0: Very negative

**Use For:**
- Tone matching
- Platform selection
- Audience targeting

## Transcript

**Full Text:**
- Complete transcript of audio/video
- Timestamped
- Editable

**Features:**
- Search within transcript
- Jump to timestamp
- Export as SRT (subtitles)
- Copy to clipboard

**Example:**
```
[00:00] Welcome to my kitchen. Today we're making butter chicken.
[00:15] First, we'll marinate the chicken in yogurt and spices.
[00:45] Now let's make the tomato-based sauce...
```

## Key Moments

**Important Timestamps:**
- Highlights of content
- Ranked by importance
- Perfect for clips

**Example:**
```
High Importance:
- 00:15 - Marinating chicken
- 00:45 - Making sauce
- 02:30 - Final plating

Medium Importance:
- 01:20 - Cooking tips
- 03:00 - Serving suggestions
```

**Use For:**
- Creating shorts/reels
- Chapter markers
- Highlight clips

## Visual Analysis

**For Videos:**
- Scene detection
- Object recognition
- Face detection
- Text in video

**Example:**
```
Scenes Detected: 5
- Kitchen setup (0:00-0:30)
- Ingredient prep (0:30-1:00)
- Cooking (1:00-2:30)
- Plating (2:30-3:00)
- Final shot (3:00-3:45)

Objects Detected:
- Cooking utensils
- Ingredients (chicken, tomatoes, spices)
- Kitchen appliances
```

## Editing Results

**You Can Edit:**
- Summary text
- Keywords
- Domain
- Sentiment
- Transcript
- Key moments

**How to Edit:**
1. Click "Edit" button
2. Modify text
3. Click "Save"
4. Re-generate outputs if needed

## Exporting Data

**Export Formats:**
- **PDF** - Full report
- **JSON** - Raw data
- **CSV** - Spreadsheet
- **SRT** - Subtitles

**How to Export:**
1. Click "Export" button
2. Select format
3. Click "Download"

**What's Included:**
- Summary
- Keywords
- Transcript
- Key moments
- Metadata

## Tips

- **Review carefully** before generating outputs
- **Edit keywords** for better SEO
- **Check domain** for accurate results
- **Use key moments** for clips
- **Export transcript** for captions
- **Save analysis** for future reference
