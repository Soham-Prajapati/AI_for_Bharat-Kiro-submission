# 🎨 Generation Studio Guide

## Overview

Generate platform-optimized content from your analyzed content.

## Select Platforms

**Available Platforms:**

### Social Media
- ☑️ YouTube Short (60s vertical)
- ☑️ YouTube Video (description)
- ☑️ Instagram Reel (caption + hashtags)
- ☑️ Instagram Post (caption)
- ☑️ TikTok (caption + hashtags)
- ☑️ Twitter Thread (10 tweets)
- ☑️ Twitter Post (single tweet)
- ☑️ LinkedIn Post (professional)

### Publishing
- ☑️ Blog Post (SEO optimized)
- ☑️ Email Newsletter

**How to Select:**
1. Check boxes for desired platforms
2. Click "Select All" for all platforms
3. Click "Generate"

## Customization Options

### Tone

**Choose Tone:**
- **Professional** - Formal, business-like
- **Casual** - Friendly, conversational
- **Humorous** - Funny, entertaining
- **Inspirational** - Motivating, uplifting
- **Educational** - Informative, teaching

### Length

**Choose Length:**
- **Short** - Brief, concise (50-100 words)
- **Medium** - Balanced (100-200 words)
- **Long** - Detailed (200-500 words)

### Style

**Additional Options:**
- Include emojis
- Add hashtags
- Include call-to-action
- Add questions
- Use bullet points

## Editing Generated Content

**Edit Features:**
- Text editor with formatting
- Character counter
- Hashtag manager
- Emoji picker
- Link shortener

**How to Edit:**
1. Click on platform card
2. Click "Edit" button
3. Modify text
4. Click "Save"

**Tips:**
- Stay within character limits
- Use platform-specific features
- Test different variations
- A/B test content

## Approval Workflow

**For Teams:**

### Step 1: Submit for Review
1. Generate content
2. Click "Submit for Review"
3. Add reviewers
4. Add notes

### Step 2: Review
- Reviewers get notification
- Can comment and suggest edits
- Approve or request changes

### Step 3: Revise
- Make requested changes
- Re-submit for review

### Step 4: Final Approval
- All reviewers approve
- Content ready to publish

## Publishing

### Direct Publishing

**Connected Platforms:**
- Link your social media accounts
- One-click publishing
- Schedule posts

**How to Connect:**
1. Go to Settings → Integrations
2. Click "Connect" for each platform
3. Authorize access
4. Start publishing!

**Publishing Options:**
- **Publish Now** - Post immediately
- **Schedule** - Set date/time
- **Save Draft** - Publish later

### Download Content

**Download Formats:**
- **Text** (.txt)
- **Word** (.docx)
- **PDF** (formatted)
- **JSON** (raw data)

**How to Download:**
1. Select platforms
2. Click "Download"
3. Choose format
4. Save to computer

**Batch Download:**
- Download all platforms at once
- Organized in ZIP file
- Includes metadata

## Troubleshooting

**Generation Failed:**
- Check internet connection
- Try again
- Contact support

**Content Too Long:**
- Select "Short" length
- Edit manually
- Split into multiple posts

**Hashtags Not Working:**
- Check platform limits
- Remove special characters
- Use trending hashtags

**Can't Publish:**
- Check account connection
- Re-authorize access
- Check platform status
