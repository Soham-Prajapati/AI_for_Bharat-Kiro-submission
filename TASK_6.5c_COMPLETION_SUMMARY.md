## How to Use the System

### Quick Start (5 minutes)
1. Read **DEMO_PRACTICE_README.md** (this file explains everything)
2. Print **DEMO_QUICK_REFERENCE.md** (keep it handy)
3. Schedule Session 1 using **DEMO_PRACTICE_SCHEDULE.md**

### For Each Practice Session (35 minutes)
1. **Before (10 min):** Review previous feedback, setup equipment
2. **During (5 min):** Deliver full demo, team takes notes
3. **After (20 min):** Record times, collect feedback, identify improvements

### Track Progress
- Use **DEMO_PRACTICE_TRACKER.md** to log each session
- Team fills out **DEMO_FEEDBACK_FORM.md** during practice
- Monitor confidence trend (target: 9/10 by Session 10)
- Monitor timing trend (target: 5:00 ±5 seconds by Session 10)
